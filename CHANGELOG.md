# Changelog

## 7.0.4+16

- Choices with a comma, like "Tacos, burritos", now load from Saved Choices in one piece.
- Deleting a choice no longer deletes a saved list with the same name.
- Blank choices can't be added.
- Back now clears a selection instead of closing the app.
- Clearer Roll button, help, saved lists and empty screen.
- Wheel labels are readable on every colour and long ones fit.
- Status bar icons are visible in light mode.
